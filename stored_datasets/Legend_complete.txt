---------------------------- STRUCTURAL ESTIMATES ---------------------------- 

est_rho_unique = individual estimate of "rho" for the model in ECMA (2020) where rho is the same between alternatives
est_rho_3x3_bin, est_rho_3x3_ter, est_rho_3x3_quat = individual estimate of "rho" for the model in ECMA (2020) where rho changes by cardinality of the menus
att_sal = individual estimate of "rho" for the model in ECMA (2020) where rho changes for each alternative
H_nosalience1, H_nosalience4 = estimates for the model "gamma" in ECMA (2020). The first refers to the probability to be type 1, namely consider only one alternative,
				The second refers to the probability to be type 4, namely consider all four alternatives.
H_salience1, Hsalience4 = estimates for the model "gamma" in ECMA (2020). The first refers to the probability to be type 1, namely consider only one alternative,
				The second refers to the probability to be type 4, namely consider all four alternatives. Here, there is a level of salience that changes for each
				alternative.
H_saliencerand_1, H_saliencerand_4, H_saliencerand_5 = estimates for the model "gamma" in ECMA (2020). The first refers to the probability to be type 1, namely consider only one alternative,
				The second refers to the probability to be type 4, namely consider all four alternatives. The last refers to the probability to be type 5, namely
				to be a uniform randomizers. Here, there is a level of salience that changes for each alternative plus a fifth type that simply randomize uniformly.
